# Guía de Usuario - Sistema Cartera

## Propósito

Esta guía resume, de forma práctica y en lenguaje sencillo, cómo se utiliza el Sistema Cartera desde la perspectiva del usuario final.

El sistema está pensado para consultar información de cartera, revisar ventas, registrar transacciones, analizar reportes y cerrar sesión de forma segura.

---

## 1. Acceso al sistema

Para ingresar, el usuario debe abrir la pantalla de inicio de sesión y escribir sus credenciales:

- Usuario
- Contraseña

Cuando los datos son correctos, el sistema redirige automáticamente a la página principal.

Si el navegador recuerda las credenciales, el usuario puede ver los campos completados automáticamente. En ese caso, solo debe confirmar el ingreso.

---

## 2. Pantalla de inicio

La página principal muestra una vista general del sistema de cartera.

En esta pantalla el usuario puede:

- Ver un resumen operativo general.
- Revisar indicadores principales.
- Acceder a las secciones de ventas, transacciones y reportes.
- Actualizar la información visual desde el botón correspondiente.

Esta pantalla sirve como punto de entrada para desplazarse por el resto del sistema.

---

## 3. Navegación principal

En el lateral izquierdo se encuentra el menú principal.

Desde allí el usuario puede entrar a:

- Inicio
- Ventas
- Transacciones
- Reportes

En la parte inferior del lateral se muestra la información de la sesión activa y el botón para cerrar sesión.

---

## 4. Sección de ventas

La sección de ventas está orientada a la carga y revisión de información comercial.

El usuario puede:

- Cargar un archivo con registros de ventas.
- Revisar los datos importados antes de confirmar acciones.
- Buscar registros dentro de la tabla.
- Consultar montos, clientes y estados asociados.

El sistema presenta la información de forma organizada para facilitar la revisión de ventas registradas.

---

## 5. Sección de transacciones

La sección de transacciones permite consultar movimientos de dinero y su relación con ventas existentes.

El usuario puede:

- Revisar transacciones registradas.
- Ver montos aplicados.
- Consultar saldos pendientes o saldos a favor.
- Buscar por cliente, referencia o datos relacionados.

Esta pantalla ayuda a identificar pagos, abonos y movimientos que aún no han sido aplicados completamente.

---

## 6. Sección de reportes

La sección de reportes ofrece una vista más analítica de la información.

El usuario puede:

- Cambiar entre distintos modos de análisis.
- Aplicar filtros según la necesidad de consulta.
- Revisar totales, estados y distribución de datos.
- Consultar tablas y visualizaciones más detalladas.

Esta sección está pensada para obtener una lectura más completa de la cartera y de sus movimientos.

---

## 7. Información de sesión

En el lateral izquierdo, debajo del menú principal, el sistema muestra:

- El usuario en sesión.
- El rol o nombre visible asociado a la cuenta.
- El botón de cierre de sesión.

Esto permite identificar con claridad quién está usando la aplicación en ese momento.

---

## 8. Cerrar sesión

Cuando el usuario termina de trabajar, puede pulsar el botón de cerrar sesión.

Al hacerlo, el sistema:

- Finaliza la sesión activa.
- Devuelve al usuario a la pantalla de acceso.
- Evita que queden abiertas las páginas protegidas sin autenticación.

---

## 9. Comportamiento de la interfaz

La interfaz está pensada para ser clara y ordenada.

El sistema mantiene una navegación lateral visible y un diseño consistente entre pantallas.

Cuando una página tiene mucho contenido, el usuario puede desplazarse hacia abajo sin perder la estructura general de la navegación.

---

## 10. Recomendaciones de uso

Para una mejor experiencia, se recomienda que el usuario:

- Utilice un navegador moderno.
- Mantenga la sesión abierta solo mientras esté trabajando.
- Revise los datos importados antes de continuar con acciones importantes.
- Cierre sesión al terminar su jornada.

---

## 11. Resumen rápido del flujo

1. El usuario ingresa con su cuenta.
2. El sistema muestra el panel principal.
3. El usuario navega entre ventas, transacciones y reportes.
4. El sistema muestra la sesión activa en el lateral.
5. El usuario cierra sesión al terminar.

---

## 12. Qué puede esperar el usuario

El usuario puede esperar una interfaz centralizada para consultar y revisar la información de cartera, con navegación simple, vista resumida, secciones especializadas y cierre de sesión seguro.
